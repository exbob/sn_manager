# SN Manager 使用手册（Windows）

面向序列号管理员：介绍如何安装启动本软件，以及主数据、生成、查询、改状态、导出等日常操作。无需联网、无需登录。

更偏开发与产品规格的内容见仓库 [`PRD.md`](PRD.md) 与根目录 [`README.md`](../README.md)。

---

## 1. 简介

**SN Manager** 是单机桌面工具，用于：

- 按约定格式（当前为 **Version A**，固定 17 位）批量生成设备序列号（SN）
- 查询已生成的 SN，并按条件筛选
- 将 SN 标记为 未使用 / 已使用 / 作废
- 导出烧写用的文本文件，和 Excel 备份

全部数据保存在本机单个 SQLite 文件 `sn_manager.db` 中，与程序目录放在一起，便于备份与迁移。

---

## 2. 安装与启动

### 2.1 获取发行版

1. 打开本项目的 GitHub 仓库页面。
2. 进入 **Releases**，下载正式发布的 **`sn-manager-windows.zip`**（由推送 `v*` / `V*` 标签触发构建）。
3. （可选）若需试构建、尚未发 Release：在 GitHub **Actions** → **Release Windows GUI** → **Run workflow**，完成后从该次运行的 **Artifacts** 下载同名 zip（不会自动创建 Release）。

### 2.2 解压与运行

1. 将 zip **完整解压**到本机固定目录（例如 `D:\tools\sn-manager\`）。请保留解压后的目录结构，不要只拷贝单独一个 `.exe`。
2. 双击运行目录中的 **`sn-manager.exe`**。
3. 首次运行会在**同一目录**自动创建（或使用已有）**`sn_manager.db`**。

主界面左下角会显示当前构建的版本字符串（便于核对发行包来源）。

### 2.3 数据文件位置

| 文件 | 说明 |
| ---- | ---- |
| `sn-manager.exe` 及依赖目录 | 程序本体（onedir 打包），用于读写数据库 |
| `sn_manager.db` | 全部主数据与 SN 记录；与程序本体同目录 |

迁移到另一台电脑时：关闭程序后，把整个程序目录（至少含 exe 所在目录与 `sn_manager.db`）一并复制即可。

## 3. 主界面概览

启动后即为**查询主界面**，大致分为左右两栏。

### 左侧

- **筛选条件**：完整 SN、型号、批次、单位、市场、状态、生产日期范围（「日期从」「日期到」）
- 按钮（自上而下）：**查询**、**生成**、**主数据**
- 左下角：应用版本号（只读）

### 右侧

- 标题行：**结果表**、**北京时间**（复选框，默认勾选）、**全选**
- 中间：结果表格（可多选；选中行以浅天蓝高亮）
- 底部左侧：`共 N 条，已选 M 条`
- 底部右侧：**改状态**、**导出**（须先选中至少一行才可点击）

**北京时间**：勾选时，表中「创建时间」「更新时间」按北京时间（`YYYY-MM-DD HH:MM:SS`）显示；取消勾选则显示库内 UTC 原文。切换勾选会立刻重绘当前结果，不必重新查询。导出文件中的时间仍为 UTC。

## 4. 主数据维护

生成与筛选时，型号、批次、单位、市场**只能从已维护的主数据中下拉选择**，不能在生成对话框里临时新增。

### 4.1 打开与确认

1. 点击左侧 **主数据**。
2. 对话框内有四个页签：**型号**、**批次**、**单位**、**市场**。
3. 每页可 **添加** / **删除** 行；编码与名称均需填写。名称去首尾空格后不能为空，长度不超过 64。
4. 点 **确认**：本次修改写入数据库并关闭。
5. 点 **取消**：放弃全部未确认修改并关闭。

首次安装后，**单位**与**市场**通常已有种子数据（如单位「1 自己生产」「2 赛威思」；市场「0 不限」「1 中国」等）。**型号**与**批次**一般需按实际情况自行添加。

### 4.2 编码格式（录入时注意）

| 类型 | 编码长度 | 说明 |
| ---- | -------- | ---- |
| 型号 | 5 个字符 | 字母或数字（界面会按规则校验） |
| 批次 | 2 个字符 | 字母或数字 |
| 单位 | 1 个字符 | 字母或数字 |
| 市场 | 1 个字符 | 字母或数字 |

下拉与表格中常显示为「编码 + 空格 + 名称」，便于辨认。

### 4.3 删除限制

若某条主数据的编码已被任意已生成的 SN 引用，则**不能删除**，软件会提示。未被引用的才可删。

## 5. 生成 SN

1. 点击左侧 **生成**，打开「生成序列号」对话框。
2. 下拉选择：**型号**、**批次**、**单位**、**市场**（须事先在主数据中维护齐全）。
3. 选择 **生产日期**（默认当天，允许改成其它真实公历日期，便于补录）。
4. 填写 **数量** N（≥1）：N=1 为单个；N>1 为批量，同一入口。
5. 点 **确定**：在一次事务中连续分配当日序号并写入；新记录状态默认为 **未使用**。对话框关闭后，右侧结果表**仅展示本批**新生成的 SN，并默认选中。
6. 点 **取消**：不生成。

### 常见失败情况

- 主数据为空或未选齐：提示先维护并选择型号、批次、单位与市场。
- 当日该「型号 + 批次」剩余序号不足 N：整批回滚，不写入任何一条；请更换**生产日期**或**硬件批次**后再试。
- 每个「生产日 + 型号 + 批次」最多可分配序号 `000`–`FFF`（十进制 0–4095）。作废记录仍占用序号，**不会回收**。

当前软件仅生成 **Version A**（SN 首字符为 `A`）。字段含义见文末附录。

## 6. 查询

1. 在左侧设置筛选条件：
   - **完整 SN**：可填完整 17 位（精确匹配场景）
   - **型号 / 批次 / 单位 / 市场**：下拉；首项为空表示不限
   - **状态**：默认「全部」；也可选未使用 / 已使用 / 作废
   - **日期从 / 日期到**：默认不启用；勾选旁侧「启用」后，才按生产日期下界/上界过滤
2. 点击 **查询**。
3. 右侧显示匹配结果；底部显示 `共 N 条，已选 M 条`。

### 多选与全选

- 单击选中一行；可用 Ctrl / Shift 多选（与常见桌面表格一致）。
- **全选**：选中当前结果表中的全部行。
- 未选中任何行时，**改状态**与**导出**按钮为禁用状态。

---

## 7. 改状态

每个 SN 有三种状态，界面显示为：

| 界面文案 | 含义 |
| -------- | ---- |
| 未使用 | 尚未投入使用（新生成默认） |
| 已使用 | 已使用（例如已烧写） |
| 作废 | 作废；记录仍保留在库中，可查、可选中导出 |

三种状态可**任意互改**。作废**不删除**记录，也**不回收**当日序号。

操作步骤：

1. 在结果表中选中一行或多行。
2. 点击 **改状态**，选择目标状态后确定。
3. 表中状态与「更新时间」会刷新。

---

## 8. 导出

须先在结果表中**选中**要导出的行（可用「全选」）。

1. 点击 **导出**。
2. 在对话框中勾选导出类型（可多选，至少一种）：
   - **烧写文本 (sn\_\<SN\>.txt)**：默认勾选。每个选中 SN 在导出目录下写一个文件，文件名 `sn_<设备序列号>.txt`，内容仅一行该序列号；同名已存在则覆盖。
   - **导出 Excel (.xlsx)**：默认不勾选。在导出目录下写一个 Excel，文件名为确认导出时的本地时间 `YYYYMMDDHHmmss.xlsx`（例：`20260731152950.xlsx`），含 SN、解析字段、状态、时间等。
3. **导出路径**：共用一个**目录**（不是单个文件路径）；默认一般为程序所在目录。可点「浏览…」更换。
4. **导出后标为已使用**：默认勾选。仅当勾选的导出类型**全部写成功**后，才将本次选中的 SN 批量改为「已使用」；任一失败则**不改状态**（已写出的文件可能已保留在磁盘上）。
5. 点 **确定** 执行；**取消** 则不导出。

写出顺序（若两种都勾选）：先烧写文本，再 Excel。

## 9. 备份与注意事项

### 备份与恢复

- **备份**：关闭程序后，复制同目录下的 `sn_manager.db` 到安全位置（可按日期命名多份）。
- **恢复**：关闭程序，将备份文件放回 exe 同目录并覆盖当前库（覆盖前请再确认已无未备份的新数据）。

### 重要注意事项

1. **勿双开**：同一台机器不要同时运行多个实例且指向同一 `sn_manager.db`，否则可能造成 SQLite 写入冲突或数据损坏。
2. **整目录使用**：Windows 发行版为 onedir，请使用解压后的完整目录，不要孤立移动单个 exe。
3. **杀毒/权限**：若首次运行被拦截，请按公司 IT 策略放行本目录；确保对程序目录有读写权限（否则无法创建或更新数据库、无法导出）。
4. **序号不回收**：作废或误生成占用的序号不会回到可用池；序号触顶时请换日期或批次。
5. **主数据先于生成**：重新启用时，先维护型号与批次，再生成 SN。

## 10. 附录：Version A 字段说明

Version A 的 SN 为固定 **17** 个字符，数字与大写字母。格式如下：

| 字符位置 | 示例 | 说明 |
| -------- | ---- | ---- |
| 1 | A | SN 格式版本（大写字母，当前为 A） |
| 2–6 | SVG14 | 产品型号（5 字符，字母或数字） |
| 7–8 | 05 | 硬件批次（2 字符，字母或数字） |
| 9 | 1、2… | 生产单位（1 字符） |
| 10 | 0、1、2、3… | 投放市场（1 字符；如 0 不限、1 中国等） |
| 11–12 | 26 | 生产年（两位数字，26 表示 2026 年） |
| 13 | 1–9、A–C | 生产月（1=1 月 … 9=9 月，A=10 月，B=11 月，C=12 月） |
| 14 | 1–9、A–V | 生产日（1=1 日 … 9=9 日，A=10 日 … U=30 日，V=31 日） |
| 15–17 | 000–FFF | 设备序号（三位十六进制）；同一「日 + 型号 + 批次」下从 0 递增，最大 4095（`FFF`） |

### 实例：`ASVG140521261CF04`

| 位置 | 值 | 说明 |
| ---- | -- | ---- |
| 1 | A | SN 版本 |
| 2–6 | SVG14 | 产品型号 |
| 7–8 | 05 | 硬件批次 |
| 9 | 2 | 生产单位（示例：赛威思） |
| 10 | 1 | 市场（示例：中国） |
| 11–12 | 26 | 2026 年 |
| 13 | 1 | 1 月 |
| 14 | C | 12 日 |
| 15–17 | F04 | 当日该型号+批次下的序号（十六进制，对应十进制 3844） |

首期仅实现 Version A；版本号首字符预留后续扩展。
